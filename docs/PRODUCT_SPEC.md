# MobileUI 产品与 UI 规范

## 定位

MobileUI 是跨 Flutter、React Native 和 ArkTS 的应用母模板。派生产品只替换品牌包、
文案、远程配置和业务模块，不修改核心启动、认证、会员、设置、状态及反馈语义。

## 页面地图

| 模块 | 页面 | 核心行为 |
|---|---|---|
| 启动 | Logo | 品牌识别，点击进入运营 Splash |
| 启动 | 运营 Splash | 广告、活动或新功能；支持跳过和远程配置 |
| 启动 | 首次引导 | 仅首次或重大版本展示 |
| 认证 | 登录/注册 | 邮箱、密码、协议与平台登录扩展点 |
| 认证 | 找回密码 | 邮箱 → 验证码 → 新密码 → 成功 |
| 首页 | 通用首页 | 运营位、快捷功能、内容卡片、最近动态、底部导航 |
| 我的 | 个人中心 | 资料、会员、统计、订单、优惠券、邀请与退出 |
| 会员 | 会员中心 | 权益、方案对比、订阅确认、订单和恢复购买 |
| 设置 | 设置首页 | 账户、安全、设备、通知、隐私、通用、主题、语言等 |
| 通知 | 通知中心 | 系统通知、业务通知、已读和清理 |

## 全局反馈

- Toast：成功、信息和失败，默认 2.4 秒，不阻断任务。
- Alert：说明需要关注但无需复杂选择的问题。
- Confirm Dialog：退出、注销、删除、付款等决策。
- Bottom Sheet：筛选、方案选择、分享和轻量编辑。
- Banner：离线、服务异常和版本更新等持续状态。

## 状态模型

页面按需覆盖 `idle / loading / success / empty / error / offline /
unauthorized`。状态互斥，不使用多个布尔值组合。认证过期统一进入登录路由，
可恢复错误必须提供重试。

## 品牌包

- 名称、Logo、启动图
- 主色和辅助色
- 字体及排版比例
- Splash 运营素材
- 会员名称、权益和价格
- 协议、隐私、客服和商店信息

- 品牌：`#A84444`；按下：`#8F3737`；浅色品牌背景：`#F6E9E9`
- 浅色背景：`#F6F7F9`；表面：`#FFFFFF`；边框：`#E4E7EC`
- 主文字：`#17191D`；次文字：`#667085`
- 成功：`#2C9A5E`；警告：`#D58B21`；错误：`#D24B4B`
- 按钮圆角 12、卡片 16、弹层 24；间距基于 4pt。
- 图标统一为 24×24 SVG，2px 描边和 `currentColor`。
